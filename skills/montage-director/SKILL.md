# Montage Director

## Огляд

Проведи користувача повним робочим маршрутом монтажу: від сирої теки з матеріалом до переглянутого результату у вибраному редакторі. Користувач може бути дилетантом — він лише подає матеріал і відповідає на короткі питання. Усі технічні рішення приймай сам, спираючись на канон.

## Джерело правди

Знайди корінь канону в такому порядку:

1. змінна середовища `MONTAGE_WORKFLOW_ROOT`;
2. поточна тека або її предки, що містять `knowledge/canon/index.md`;
3. якщо немає — повідом, що треба клонувати `vaoferi/montage-workflow` і вказати шлях.

Читай `knowledge/canon/index.md` і далі файли за потребою етапу. Канон — універсальний; доменні інстанси (`knowledge/domains/`) застосовуй лише коли домен збігається.

## Принципи (неухильно)

- **Оригінали незмінні**: нічого не перезаписувати, не перекодовувати поверх, не видаляти. Усі позначки — sidecar-файли, похідні — окремо.
- **Done = evidence**: не «команда успішна», а перевірений результат (перегляд/прослух, кадри, ffprobe-виміри).
- **Test before batch**: будь-який processing спочатку на малому фрагменті, потім масштабування.
- **Не питай про те, що можна з'ясувати сам**: читай метадані, файли, транскрипти, логи.
- **Системні пакети — лише з дозволу**; pip-інструменти з безкоштовних джерел став автоматично, коли потрібні.

## Instructions (Маршрут)

### 0. Doctor
Запусти `scripts/doctor.py --json`. Зафіксуй: ffmpeg/ffprobe, exiftool, транскрибатор, встановлені редактори. Якщо немає транскрибатора — встанови `faster-whisper` через pip. Якщо немає ffmpeg — попроси дозвіл на системний пакетний менеджер із точною командою.

### 1. Обсяг матеріалу

Одне питання: **увесь матеріал у теці чи конкретні файли/теки?** Більше на цьому етапі не питай.

### 2. Інвентаризація

`scripts/inventory.py <dir> --json` → збережи JSON у робочу теку проєкту. Паралельно, якщо є субагенти, — з етапом 3.

### 3. Транскрипція

Безкоштовний локальний транскрибатор (`faster-whisper`, модель за мовою матеріалу). Зберігай JSON із сегментами (`id`, `start`, `end`, `text`) на файл. Якщо доступний Resolve Studio — можна його транскрипцію, але локальний whisper універсальніший.

### 4. Маркування шлаку

`scripts/filler_mark.py <transcript.json>` → створює `<transcript>.flags.json`. Повтори, оговорки, єкання/бекання позначай кандидатами на видалення. **Не видаляй нічого фізично.** Не показуй користувачеві ці позначки як остаточні рішення — це чернетка для сценарію.

### 5. Інтерв'ю з фактами

Маючи транскрипт і інвентар, постав мінімум питань: мета ролика, платформа/формат, цільова тривалість, тон, обов'язкові моменти/люди, чи є заборонені фрагменти. Не питай про те, що вже видно з матеріалу. Пропонуй розумні дефолти й проси підтвердити, а не вигадувати з нуля.

### 6. Сценарій

Збудуй з відповідей і матеріалу: hook → розвиток → фінал. Думки завершені, жодних обрізаних речень. Покажи сценарій користувачеві на затвердження перед монтажем.

### 7. Монтаж

Формуй монтаж за каноном (`canon/style/`, `canon/audio/`, `canon/process/`). Позначки з етапу 4 — кандидати на вирізання. Зберігай монтажне рішення у `timeline.json` проєкту з `decisions.md` (чому кожен вибір). Оригінали не чіпай.

### 8. Відкриття в редакторі

Запропонуй зі списку встановлених (doctor): DaVinci Resolve, Premiere, Final Cut, FilmCraft або інші знайдені. Якщо немає жодного — запропонуй встановити (Resolve безкоштовний; FilmCraft open-source) з точним посиланням/командою, але не встановлюй системні пакети без дозволу. Імпортуй проєкт у вибраний редактор або відкрий змонтований рендер для перегляду.

### 9. QC

Чекліст перед оголошенням готовності:

- жодних обрізаних думок (крім явного запиту користувача);
- жодних обрізаних голів/кінцівок фраз;
- повтори, оговорки, єкання/бекання прибрані або позначені до виправлення;
- немає очевидного шлаку: порожні паузи без змісту, чорні кадри, раптові стрибки;
- результат реально переглянуто/прослухано, ключові місця перевірено, ffprobe-виміри знято;
- залишок проблем — списком з рекомендаціями, без «успішно» за exit code.

## Підбір зовнішніх скілів

Коли потреба виходить за вбудовані скрипти (сценарій, субтитри, motion-графіка, denoise), обирай із `knowledge/canon/tools/skill-repos.md`. Перед використанням будь-якого зовнішнього скіла:

1. sync з офіційного репо до актуального стану;
2. зафіксуй commit SHA;
3. оглянь дифф;
4. перший запуск — smoke test на малому фрагменті;
5. результат переглянь зі звуком.

## Паралельність

Є субагенти — запускай інвентар і транскрипцію паралельно, далі за маршрутом. Немає — послідовно, той самий результат.

## Examples

Ініціалізація в новій теці з матеріалом:

```text
Користувач: «Змонтуй відео з теки /path/to/footage»
Агент:
1. python3 scripts/doctor.py --json
2. Питання: «Увесь матеріал у /path/to/footage чи конкретні файли?»
3. python3 scripts/inventory.py /path/to/footage --json > inventory.json
4. faster-whisper → transcript.json для кожного відео зі звуком
5. python3 scripts/filler_mark.py transcript.json
6. Інтерв'ю за фактами → сценарій на затвердження
7. timeline.json + decisions.md → монтаж → вибір редактора → QC
```

## Скрипти

- `scripts/doctor.py --json` — інструменти, транскрибатор, редактори; людський звіт за замовчуванням.
- `scripts/inventory.py <dir> --json` — інвентар медіа через ffprobe.
- `scripts/filler_mark.py <transcript.json>` — sidecar-флаги повторів/філерів; оригінал не змінюється.

Усі скрипти — Python 3.9+, лише stdlib.
