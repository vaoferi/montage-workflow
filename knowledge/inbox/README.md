# Inbox — сирий матеріал

Сюди власник кладе зібраний матеріал: нотатки, референси, приклади стилю, інструкції з різних джерел.

Правила:

- Файли в inbox — **недоторканний аудит**: після отримання не редагуються і не видаляються.
- Дистиляція: агент витягує правила → оновлює `knowledge/canon/` (кожне правило з джерелом і датою) → фіксує зміни в `knowledge/canon/CHANGELOG.md` → звітує власнику.
- Конфлікт правил: перемагає свіжіше джерело; обидві версії — у CHANGELOG.
