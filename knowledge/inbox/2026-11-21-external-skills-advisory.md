## **Як би я зібрав твою систему**

**Creator Skills + Vyral**

Сюжет, сильний початок, цілісні думки

**Cinema Skills + Visual Storytelling**

Розкадрування, підбір візуальних вставок

**Herk Edit Kit + FFmpeg**

Нарізка, монтаж, звук, синхронізація

**Remotion + фінальний QC**

Анімації, субтитри, перевірка готового MP4

Для генерації нових зображень і кадрів скіли лише готують завдання та промпти. Потрібно підключити окремий генератор. У ChatGPT уже доступні спеціалізовані скіли Magnific для `previs-storyboard`, `cinematic-shots`, `consistent-characters` та `video-finishing`; а Descript має AI-редагування існуючих відеопроєктів. Це окремі інтеграції, не локальні скіли OpenCode.

## **Встановлення в OpenCode**

Почав би з цього мінімального набору:

```
# Сюжет
npx skills add novincode/creator-skills --skill story-craft -a opencode

# Розкадрування
npx skills add novincode/creator-skills --skill storyboarding -a opencode

# Сильний початок відео
npx skills add vyralcontent/content-skills --skill viral-hooks -a opencode

# Монтаж розмовних відео
npx skills add social-media-skills/video-editing-skill -a opencode

# Технічний монтаж
npx skills add kajisho5/ffmpeg-skill -a opencode

# Motion-графіка
npx skills add remotion-dev/skills -a opencode
```

Для Herk Edit Kit краще встановлювати цілий репозиторій за його README, оскільки там важливі не лише скіли, а й скрипти, шаблони та локальний рушій.

**Підводні камені:** не встановлюй одразу всі 50 скілів. Частина перекриває функції інших. Перевір код перед запуском, а змонтований ролик обов'язково переглядай зі звуком: AI часто бездоганно вирізає паузу разом із половиною сенсу.

**Мій вибір для першого тесту:** Herk Edit Kit + Creator Skills + FFmpeg Skill. На одному реальному відео перевірити якість сюжету, доречність картинок, коректність субтитрів і те, чи агент не залишив обірваних думок. Це покаже набагато більше, ніж встановлення двадцяти неперевірених скілів. їх треба зробити частиною мого воркфлоу але з автооновленням з офіційних репо перед застосуванням у роботі і цей https://github.com/mattpocock/skills
