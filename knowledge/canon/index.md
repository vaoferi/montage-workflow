# Канон — індекс (універсальний)

Оновлено: 2026-11-21. Джерела надходять у `knowledge/inbox/`; історія змін — `CHANGELOG.md`.

Канон містить **універсальні** правила, застосовні до будь-якого відеомонтажу. Доменні конкретизації живуть окремо в `knowledge/domains/` і ніколи не замінюють канон.

| Область | Файл | Про що | Статус |
|---------|------|--------|--------|
| style | `style/editing-grammar.md` | Правила монтажної граматики: виправдання кадру, пріоритети, тримання, повтори, рух камери, continuity, story first, salvage | active |
| style | `style/analysis-method.md` | Ієрархічний трипрохідний аналіз матеріалу, технічні флаги, дублікати, класифікація, маркери, безпека автоматизації | active |
| audio | `audio/audio-priority.md` | Пріоритет звуку, ducking, збереження природних звуків | active |
| qc | `qc/qc-protocol.md` | Повний перегляд у реальному часі, сигнали проблем, два проходи | active |
| tools | `tools/resolve-21.md` | Можливості Resolve 21/21.1, колірний порядок | active (перевіряти probe()) |

Поза каноном:

- `knowledge/domains/` — доменні інстанси (приклади конкретизації універсальних правил для типу продукту). Зараз: `wedding.md`.

Ще немає матеріалу: `platform/` (специфікації платформ), `delivery/` (матриця експорту, неймінг).
