# Web showcase tool selection
Source: verified upstream documentation and owner brief, 2026-11-24. Use with knowledge/domains/web-project-showcase.md; do not install every tool.
- Stageshow: https://github.com/benjitaylor/skills/tree/main/stageshow — verified SKILL.md version 1.1.1, React/plain CSS authored illustrations, not live automation. Review candidate 299140fafd08df55a9c234e610c3f64af3f45531. Read references/craft.md, framing.md, motion.md and rehearse.md from selected skill. Check package/commands at actual revision. Its documented film script and --gate are for rehearsal; verify output formats before final encoding. Use only for teaser or clearly labeled illustrative shot; never rewrite the product.
- Real demo: https://github.com/amahpour/demo-video-skills — MIT per README, review candidate 0bf99196118ea22c366c6aa88d51588889c7cb3d. Linux/WSL2 Xvfb + Chrome + ffmpeg + uv; macOS via existing Docker only if appropriate. Read skills/demo-video/SKILL.md, actual check_env.py, new_project.py and recording/editing references. Preserve user approval gates for audio. Do not assume a Windows or NAS browser runtime.
- https://github.com/paulirish/chrome-capture — review candidate c489edfd0159fb49920ed0adf4942766715d7dbb. README requires Chrome 153+ for native capture; AV1 MP4, actual page/cursor actions, 60fps optional. Check installed Chrome/CDP compatibility; otherwise existing Playwright recording, OS capture or demo-video-skills. Transcode final to H.264.
- Remotion (already registered): https://github.com/remotion-dev/skills — use code-driven framing, before/after animation, titles and vertical layouts where appropriate; check current license for rendering/commercial use, existing package versions and local capabilities. No automatic paid service.
- Optional spoken captions: https://github.com/0xpratzyy/subtle — review candidate ca28fad53b21cf1a13bfa1dab473285d11290654. Current README: Apple Silicon for mlx-whisper and Apple Vision, timed-word input possible on Linux/Intel Mac. Do not install large models for silent UI clips. Standard SRT/FFmpeg or installed tools are sufficient for most demos.
- Motion Anything and advanced 3D are optional via VAOFERI Design when task actually calls for it; do not duplicate recipe skills or add separate command per effect.
- Use existing FFmpeg/ffprobe, Creator Skills and storytelling tools in canon when they add value. A simple screen capture + cut + captions is preferred to a fragile stack. Source URLs are verified documentation references, candidate SHAs not security approvals. Review changes, license, entrypoint, scripts and dependencies before first execution. Do not globally install or expose all skills, no blind install or paid API.

## Selection
Teaser → Stageshow or existing Remotion/native animation. Live walkthrough → real Playwright/Chrome/OS capture, optionally demo-video-skills. Case study → actual baseline/current footage + FFmpeg/Remotion. All three share the same evidence and captions but not the same story. If one adapter fails, use a native equivalent and record fallback; deliver independent outputs instead of blocking whole report.
